## コアメッセージ：『Whyで考える』

本研修の最大のテイクアウェイは、**「How（やり方・手段）」に囚われず、まず「Why（なぜ・目的）」から考えること**です。

### 3つのChapterと「Why」のつながり

| 章 | 下から見る視点（How・具体） | 上から見る視点（Why・抽象） | 「Whyで考える」ポイント |
|---|---|---|---|
| **第1章：職域の線引き** | 「仕様書通りに自分のタスクを完遂した（部分最適）」 | 「組織全体の価値提供・後続（運用/QA）の破綻」 | **Why：**「システム全体を成功させるために」境界を一歩越えてボールを拾う |
| **第2章：ユーザー意見の改善** | 「顧客の言うボタンを全部足し算した（Howの鵜呑み）」 | 「製品のコアビジョン・誰のためのプロダクトか」 | **Why：**「そもそもなぜその機能が必要なのか？」を深掘りし、キメラ化を防ぐ |
| **第3章：絵に描いた餅** | 「実現不可能な机上の空論（役に立たない無駄）」 | 「未知の暗闇で全員のベクトルを揃える唯一の羅針盤」 | **Why：**「私たちが目指す理想の未来は何か？」を描く勇気が人を動かす |

## 大講堂投影に向けたデザイン設計
広い会場や大講堂の後ろの席からでもハッキリと文字が読めるよう、以下のリレイアウトを実施しています：
- **基本文字サイズ**: 21px ➔ **23〜25px** に拡大
- **見出しフォント**: 27px ➔ **33〜35px** に拡大、太字（`font-weight: 900`）で高コントラスト化
- **強調表現**: 「Why」に関する重要フレーズに黄色のアンダーラインハイライト（`.why-highlight`）を適用
- **まとめ（P19）**: 「本日持ち帰ってほしい、たった1つのこと」として、大講堂で一目で刺さる大型メッセージカードを新設

## MarpでのHTML / PDF出力方法

```bash
# HTMLスライドを生成（ブラウザで即座に大画面全画面プレゼン可能）
npx @marp-team/marp-cli --no-stdin --html "若手スキルアップ研修会/slides.md" -o "若手スキルアップ研修会/slides.html"

# PDF形式としてエクスポート（印刷・配布・オフライン大画面投影用）
npx @marp-team/marp-cli --no-stdin --html --allow-local-files "若手スキルアップ研修会/slides.md" --pdf -o "若手スキルアップ研修会/slides.pdf"
```
