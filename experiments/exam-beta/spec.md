# システム概要: 
市民が「体育館」「会議室」「温水プール」などの自治体施設を、共通のアカウントで横断検索・予約し、最後に模擬決済と予約票（PDF）を出力するシステム。

# ターゲットユーザーとユースケース
## 市民ユーザ
  - スマホまたはPCで施設検索する。
  - 検索した施設に対して予約する。
  - 予約票のPDFをダウンロードして、実際に施設を利用するときに見せる。
## 自治体職員
  - 施設管理や予約受付業務の効率化を行う。
  - 施設情報のメンテナンスを行う。
  - 施設予約状況一覧から、施設の管理者に連絡、予約状況を伝える。

# 要件
## 機能要件
- 施設検索
  - 施設名、所在地、種別（体育館、会議室、プールなど）、料金、空き状況などで検索可能
- 予約機能
  - 予約日時、人数、利用目的などを入力
  - 空き状況を確認し、予約確定
- 模擬決済機能
  - ダミーの決済QRコードを表示する。
- 予約票出力
  - PDF形式で予約票を出力
- 予約確認・変更・キャンセル機能
- ユーザー管理機能
  - ユーザー登録、ログイン、プロフィール管理

## 技術スタック
- フロントエンド: Vue.js(CDN経由)
- バックエンド: Python Flask
- フロントエンド／バックエンドがPython Flaskサーバで単一で稼働する構成とすること。
- 必要なライブラリはrequirements.txtに記載しておくこと。
- データベース: Sqlite

## UI/UX要件
- シンプルで直感的な操作性
- 多言語対応（日本語・英語・中国語）
- アクセシビリティ対応
