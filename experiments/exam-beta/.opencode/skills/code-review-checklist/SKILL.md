# Code Review Checklist Skill

## レビュー基準

### 共通
- [ ] 仕様書（docs/system_spec.md）通りに実装されているか
- [ ] 不要なコメントアウトコードが残っていないか
- [ ] エラーハンドリングが適切に行われているか
- [ ] セキュリティ上の問題（SQLインジェクション、XSSなど）がないか

### バックエンド (Python/Flask)
- [ ] ルート定義とHTTPメソッドが適切か
- [ ] DBクエリにパラメータ化されたクエリを使用しているか
- [ ] バリデーションが実装されているか
- [ ] JWT認証が適切に実装されているか

### フロントエンド (Vue.js/HTML/CSS)
- [ ] Vue.js のデータバインディングが適切か
- [ ] API呼び出しのエラーハンドリングとローディング表示があるか
- [ ] レスポンシブデザインが適用されているか
- [ ] アクセシビリティ（aria属性、ラベル）が考慮されているか
- [ ] 多言語対応が実装されているか

### テスト
- [ ] 正常系・異常系のテストが網羅されているか
- [ ] テストコード自体が読みやすいか
