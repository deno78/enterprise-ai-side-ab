# システム設計スキル

アーキテクチャや設計書を作成・更新する際は、以下の標準に従ってください。

## 1. ディレクトリ構造
- 設計ドキュメントはすべて `docs/architecture/` にMarkdown形式で配置する。

## 2. API設計方針
- RESTful APIの標準命名規則に従う。
- エラーハンドリングの標準レスポンスフォーマット（RFC 7807 準拠）を定義に含める。

## 3. シーケンス図
- コンポーネント間の複雑なやり取りは Mermaid.js のシーケンス図（```mermaid）を用いて可視化する。
